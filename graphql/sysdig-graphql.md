# Sysdig GraphQL API

Sysdig provides cloud-native security and observability for Kubernetes, containers, and cloud. The API covers runtime threat detection, compliance posture management, vulnerability management, image scanning, network security policies, and drift detection.

**Endpoint:** No native GraphQL endpoint — conceptual schema derived from Sysdig REST API
